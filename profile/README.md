# Baluarte Sentinela Universal

**Observatório centralizado das aplicações de [@luan313](https://github.com/luan313).**

Esta organização reúne os produtos de software que desenvolvo e o que é preciso para acompanhá-los em um só lugar: catálogo das aplicações, saúde e erros, relatos de bugs e custo de operação de cada uma.

## A ideia

Toda aplicação tem dono, stack, ambiente e custo. O objetivo é enxergar tudo isso de uma vez, sem depender de lembrar onde cada coisa está.

- **Catálogo:** cada repositório se descreve com um `catalog-info.yaml` e é descoberto automaticamente. *(em construção)*
- **Saúde:** painéis de erros e de disponibilidade. *(planejado)*
- **Suporte:** caixa de entrada para relatos de bugs. *(planejado)*
- **Custo:** consumo de cada aplicação, em reais, nos serviços de hospedagem onde ela roda. *(planejado)*

## O que é construído aqui

- Sites e sistemas para pequenos negócios locais: página de presença, cardápio e pedidos online, painel do dono e fidelidade de clientes.
- APIs multi-cliente e painéis administrativos.
- Ferramentas internas de monitoramento e catálogo.

## Stacks

TypeScript · React e Next.js · Node.js e Fastify · PostgreSQL · Docker · Vitest e Playwright

Catálogo e observação *(planejado)*: Backstage e Umami.
